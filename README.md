A modern, responsive, and interactive portfolio website showcasing my skills, projects, education, and achievements.

## 📖 About

This portfolio website serves as my professional online presence, highlighting my technical expertise, academic background, projects, and career aspirations.

Designed with a focus on clean UI, responsiveness, and user experience, the website provides visitors with an overview of my journey as a developer and student.

---

## ✨ Features

- Responsive Design
- Modern User Interface
- About Me Section
- Education Timeline
- Skills Showcase
- Projects Portfolio
- Resume Download
- Contact Form
- Social Media Links
- Smooth Navigation
- Mobile Friendly Layout

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Arpan-Ghosh07/Personal-Portfolio.git
```

### Navigate to Project Directory

```bash
cd Personal-Portfolio
```

### Run Locally

Open the `index.html` file in your browser or use the VS Code Live Server extension.
